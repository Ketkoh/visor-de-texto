K-01 — Preparación del repositorio y configuración de integración continua
Completada
Objetivo: establecer la infraestructura inicial del proyecto Visor de Texto, alojar el código fuente en GitHub y configurar un flujo de integración continua que compruebe automáticamente que el proyecto compila y sus pruebas unitarias se ejecutan correctamente.
Actividades realizadas
1. Creación del repositorio en GitHub
- Se creó un repositorio público llamado visor-de-texto.
- Se utilizó la cuenta de GitHub del usuario.
- Se seleccionó la licencia GNU AGPL v3.0, acorde con las decisiones del proyecto.
- Se incorporó el .gitignore correspondiente a Android, evitando subir archivos locales y elementos que no deben formar parte del repositorio, como local.properties, *.jks y *.keystore.
2. Publicación del proyecto
- Se subió la estructura inicial del proyecto Android Studio.
- Se verificó que los archivos de configuración y el código fuente estuvieran disponibles en el repositorio.
3. Creación del archivo CONTEXTO.md
- Se incorporó un documento en la raíz del repositorio con las decisiones técnicas y reglas obligatorias del proyecto.
- Se especificaron Kotlin, Jetpack Compose, el paquete de la aplicación, las restricciones de permisos, la separación del núcleo respecto de Android y las condiciones para incorporar dependencias.
- También se estableció la trazabilidad mediante identificadores RF-xx y K-xx.
4. Incorporación de Kevin como colaborador
- Se envió la invitación de colaboración al repositorio.
- Kevin confirmó que podía acceder y visualizar el proyecto.
5. Configuración de integración continua (GitHub Actions)
- Se creó .github/workflows/ci.yml.
- Se configuró un flujo automático para ejecutarse ante cambios en main, solicitudes de integración (pull requests) y ejecuciones manuales.
- El flujo prepara JDK 17 y el entorno Android SDK, ejecuta las pruebas unitarias mediante Gradle y construye la aplicación en versión debug.
6. Resolución de problemas del flujo CI
- La primera ejecución presentó un problema durante la aceptación de licencias del Android SDK.
- Se revisó y ajustó la configuración del entorno.
- También se corrigió la instalación de la plataforma Android SDK para utilizar platforms;android-37.0.
- Tras los ajustes, GitHub Actions completó correctamente el proceso.
Resultado y evidencia de cumplimiento
Criterios cumplidos
- Repositorio público disponible: Ketkoh/visor-de-texto.
- Licencia AGPL-3.0 incorporada.
- .gitignore configurado para el proyecto Android.
- Archivo CONTEXTO.md publicado.
- Kevin incorporado como colaborador y acceso confirmado.
- GitHub Actions ejecutándose correctamente, con resultado satisfactorio en la pestaña Actions.
Conclusión: K-01 se completó satisfactoriamente. El proyecto dispone de un repositorio centralizado, control de versiones, acceso compartido para el equipo y un mecanismo automatizado de verificación que permite detectar errores de compilación o pruebas ante futuras modificaciones.
